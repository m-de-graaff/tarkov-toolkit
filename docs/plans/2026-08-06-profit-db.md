# Profit Calculator & Persistence Layer Plan

> **To execute:** use the `executing-plans` skill. Steps use `- [ ]` for tracking.

**Goal:** (1) The market page becomes a categorized profit calculator — Barter flips, Craft profits, Trader resells — priced per game mode (PvP/PvE toggle drives which flea prices load). (2) Progress persistence moves from localStorage to a proper local database (IndexedDB) with schema versioning and a one-time import of existing data; the hosted-with-auth server database remains designed-and-blocked (docs/auth-design.md decisions), with the sync contract written down.

## Verified facts

- `pve/items` exists (16.4MB) — PvE flea prices are a separate dataset.
- Items carry `buyFromTrader` `{trader, priceRUB, minTraderLevel, taskUnlock, buyLimit}` and `sellToTrader` `{trader, priceRUB}` → trader-resell and best-trader-sell math is possible client-side.
- Flea *selling* incurs an in-game fee our data can't precisely model per-user (Intelligence Center level dependent) — resell profits are shown as gross spread labelled "before flea fee".
